## 1. 当前处于什么阶段

项目已完成单侧自然眼线 Demo 的开发，并在首版基础上加入完整轮廓、分步提示和眼部放大。首版已获得项目发起人的体验验收确认；v0.2 已完成自动化测试与界面检查。

**目前可以使用实时参考路径和分步操作指导。关键帧方向检查的代码与流程已经接通，并通过合成图测试，真人眼线的识别准确性仍待样本验证。**

当前一次指导一侧眼睛、一种自然眼线样式。用户通过选择左右眼、调整长度和上扬角度表达目标；尚未接入自然语言妆效理解或自动妆容推荐。

完整操作流程为：

> 选择侧别与参数 → 识别眼部并确认参考轮廓 → 采集画前基准图 → 画眼尾 → 点击检查并采集画后图 → 查看反馈 → 连接眼睑外段 → 再次检查 → 用户确认完成。

## 2. 已跑通的功能

| 功能           | 当前可以做什么                                                             | 需要明确的边界                                                   |
| -------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| 摄像头接入     | 开启、关闭、暂停、恢复；处理授权拒绝和加载失败                             | 手机摄像头需要受信任的 HTTPS；桌面移动视口测试不等于实体手机测试 |
| 眼部定位       | 使用 MediaPipe 单人脸视频模式提取眼角、眼睑等关键点                        | 定位不是身份识别；检测到关键点也不代表眼睛没有被遮挡             |
| 实时路径跟随   | 参考路径随眼部位置更新，支持左右眼、镜像、缩放以及长度和上扬角度调整       | 按眼部几何适配，不代表已经证明某条路径最适合用户                 |
| 完整轮廓       | 显示眼睑外段与渐细眼尾的填充范围                                           | 轮廓宽度是固定示意参数，尚未经过专业美妆规则验收                 |
| 分步指导       | 按“确认路径、画眼尾、连接外段、完成”推进；高亮当前段，显示起终点和方向箭头 | 由用户确认步骤完成，检查结果不会自动推进流程                     |
| 妆效预览       | 在分步轮廓与半透明深色妆效之间切换                                         | 属于示意预览，不是照片级试妆或真实产品效果预测                   |
| 眼部放大       | 在操作提示旁显示眼部局部画面；暂停或丢失定位时清空                         | 未开摄像头时显示明确标注的示意图，该数据不参与分析               |
| 关键帧采集     | 分别采集画前基准图和画后原始图，支持取消、重拍与重试                       | 用户点击检查后，仍需确认移开手与工具；没有手部自动触发           |
| 流程与异常处理 | 防止重复提交；更换侧别或修改目标后旧图和旧结果失效；人脸丢失时隐藏参考线   | 切换显示模式不会修改目标或清除有效基准图                         |
| 图像隔离       | 检查只读取原始视频图像，虚拟轮廓和放大画面不进入分析输入                   | 图片保存在当前会话内，不上传、不保存到数据库                     |

### 已接入、尚待真人验证的方向检查

当前算法路线：

> 眼部裁切与对齐 → 补偿小范围位移和亮度变化 → 提取新增深色区域 → 筛选外眼角附近的候选区域 → 拟合方向 → 与参考方向比较。

结果分为“接近参考方向、明显偏高、明显偏低、无法判断”。方向偏差超过 **10°** 暂判为明显偏离；这是 Demo 的实验阈值，比较的是图像内眼部局部坐标中的方向，不是美妆标准或真实三维角度。

模糊、闭眼、明显未对齐、大区域变化或候选不可靠时会尝试拒判；这些规则不能保证排除所有手部遮挡、睫毛和阴影。分析组件失败时明确提示“分析暂不可用”，不使用随机评分或模拟结果代替真实分析。

两次分段检查都只评价眼尾方向，暂不评价眼线粗细、连续性或整体妆效。

## 3. 当前技术栈及用途

版本依据当前 `package.json` 与 `package-lock.json`，是项目锁定版本，不表示各组件的最新版本。

| 技术                   | 当前版本或方式                          | 在项目中的职责                                                 |
| ---------------------- | --------------------------------------- | -------------------------------------------------------------- |
| React / React DOM      | 19.3.0                                  | 页面、交互和显示状态                                           |
| TypeScript             | 7.0.2                                   | 数据类型、模块接口与业务逻辑                                   |
| Vite                   | 8.3.0                                   | 本地开发服务与生产构建                                         |
| MediaPipe Tasks Vision | 1.0.1，Face Landmarker                  | 单人脸视频定位和眼部关键点提取；复用单人脸模式的内置平滑       |
| 浏览器摄像头 API       | `getUserMedia`                          | 获取实时视频                                                   |
| Canvas 2D              | 浏览器原生能力                          | 参考轮廓、妆效预览、眼部放大与原始图像采集；显示与采集通路分离 |
| OpenCV.js              | `@techstark/opencv-js` 4.12.0-release.1 | 图像对齐、区域提取和方向拟合                                   |
| 自有几何与流程代码     | TypeScript                              | 生成路径、转换坐标、管理操作步骤与检查请求                     |
| CSS                    | 原生样式                                | 页面布局、移动视口适配与视觉呈现                               |
| Vitest                 | 5.0.1                                   | 几何、状态流程及合成图算法测试                                 |
| Playwright             | 1.63.0                                  | 页面流程、异常场景和浏览器模型加载测试                         |
| Node.js / npm          | README 要求 Node.js 22.12+              | 开发、依赖安装、构建和样本测试脚本；不承担线上业务后端         |

**项目是纯前端应用。** 当前没有后端服务、账号系统、数据库或大模型调用，也没有自行训练视觉模型。MediaPipe 负责定位，OpenCV 负责图像处理，眼线路径、分步指导和反馈规则由项目代码实现。

模型、WASM 和 OpenCV.js 通过安装脚本准备到本地静态资源目录，运行时从本站加载。初次安装需要下载模型，仓库不提交约 51 MB 的生成资源。第三方来源见[第三方组件说明](third-party.md)。

## 4. 团队可以复用的模块

| 模块         | 位置                           | 提供的能力                                                 |
| ------------ | ------------------------------ | ---------------------------------------------------------- |
| 视觉定位     | `src/vision/`                  | 共用摄像头、MediaPipe 检测器、眼部位置和原始关键帧采集     |
| 路径与展示   | `src/guidance/`                | 统一眼部坐标、参考轮廓、绘制器与放大窗口                   |
| 结果检查     | `src/analysis/`                | OpenCV 加载、图像处理和方向评价                            |
| 练习流程     | `src/session.ts`               | 操作步骤、目标版本、基准图及过期检查结果隔离               |
| 页面集成     | `src/App.tsx`、`src/style.css` | 参数设置、按钮、提示和结果展示                             |
| 共享数据接口 | `src/types.ts`                 | `Target`、`VisionOutput`、`Frame`、`Evaluation` 等数据结构 |

队友应基于同一仓库和现有技术栈开发，复用已有摄像头与定位模块。公共接口变更需同步给相关模块负责人；每项功能使用独立分支，通过 Pull Request 合并。模块分工是代码职责划分，尚不代表具体成员已经认领任务。
