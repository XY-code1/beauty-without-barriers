# 无界美妆：当前功能与技术栈

更新：2026-09-24。v0.3 在 `codex/v0.3-makeup-workspace` 开发，main 保留原版。首版曾由项目发起人确认体验验收；这不等于新版或真人算法验收。

## 已实现的产品链路

工作台 → 眼线准备 → 画前照片 → 眼尾练习 → 主动拍摄检查 → 连接外段 → 再检查 → 用户确认完成。

| 板块 | 当前行为 | 边界 |
| --- | --- | --- |
| 全妆工作台 | 分类、状态、进入和退出眼线、浏览器前进后退 | 只开放眼线，其他四类仅说明 |
| 摄像头与定位 | 单一视频源和检测器、左右眼、暂停、丢失恢复 | 关键点不证明无遮挡 |
| 指引 | 按眼部位置适配、渐细轮廓、当前分段、局部/整体切换 | 只有一种自然样式，非个性化美妆标准 |
| 显示设置 | 跟着画/看效果、高对比、不透明度 | 不改变目标或清除画前照片 |
| 拍摄 | 可取消三秒倒计时、最多一秒和五个不同帧、质量择优 | 仍需用户移开手并确认；不是手部自动感知 |
| 结果 | 本次照片/画前对照、参考虚线、可靠候选实线、文字反馈 | 只判断眼尾方向，10° 为实验阈值 |
| 异常与清理 | 权限/模型/分析失败提示、拒判、过期请求隔离、结束/退出关闭摄像头 | 不保存跨会话照片或历史 |

## 技术栈与团队接口

- React 19 + TypeScript + Vite：页面和会话状态；轻量 hash 导航，没有额外路由框架。
- MediaPipe Face Landmarker：478 个面部关键点，单人 VIDEO 模式；不是身份识别。
- Canvas 2D：参考轮廓、实时放大、照片及线段叠加。分析只读取原始视频。
- OpenCV.js：对齐、亮度/小位移补偿、新增深色区域、连通区域、方向拟合和保守拒判。
- Vitest：几何、会话和真实 OpenCV 合成样本；Playwright：浏览器流程、隔离的摄像头测试替身、真实模型加载及页面布局。
- 没有后端、数据库、账号、大模型服务或图片上传接口。实际版本由 package-lock.json 锁定。

共享类型位于 `src/types.ts`。Frame 将原始像素、同帧眼部定位、时间戳、目标与版本绑定；Evaluation 的可选 evidence 标明 `after-eye-local` 坐标系，端点取自检测候选的实际投影范围。显示镜像不修改分析坐标。

`src/vision/` 管摄像头与采集，`src/guidance/` 管几何和参考绘制，`src/analysis/` 管分析及照片反馈；App 管模块入口，EyelinerPractice 管同一会话的步骤。
