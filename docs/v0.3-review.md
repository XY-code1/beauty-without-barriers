## Standards

没有发现仓库规则的硬性违反。技术栈、分支和证据口径符合约定。

三项非阻断的维护性判断：

1. **Possible Divergent Change**：EyelinerPractice 延续了旧版大组件，包含摄像头生命周期、步骤和多个界面；若下一版继续增长，可沿拍摄会话与展示的实际边界拆分。
2. **Possible Repeated Switches**：多个位置按 session.step 选择文案/视图；将来增加步骤时应统一定义，避免漂移。
3. **Possible Duplicated Code**：workspace 浏览器测试有三处相同的媒体轨道释放断言，可提取测试辅助函数。

本轮保留这些可读的局部实现，不为了审查建议引入通用状态/插件框架；不存在待处理的架构阻断。

## Spec

审查发现两项：

1. 原暂存快照按 video.currentTime 判断不同帧，可能重复采集同一解码帧。已在 `bcfa19d` 改为已解码帧计数，缺少该能力时保守单帧；新增测试先复现“期望1次、实际5次”，修复后通过。取消、后台切换测试也已加入最终回归。
2. 检测证据的左右眼/镜像/旋转缩放验证不足。已补充 OpenCV 变换照片的局部端点断言，以及四种左右眼/镜像组合的 Canvas 像素位置断言，确认黄色候选线落在已知合成照片的眼尾位置；12项算法测试与5项结果页测试通过。

没有发现明确的超范围功能。真人/手机/新手验收按规格明确待执行，不以合成样本代替。

审查计数：Standards 0项硬违反、3项维护性建议；Spec 2项发现均已处理并通过针对性验证，无遗留阻断。
